# 开饭啦 · 我的私人菜单

一个供自己使用的手机网页应用，无需账号。全部菜谱和图标都在项目内，没有外部字体、图片或 API 依赖。

## 已包含的功能

- 16 道家常菜及食材、用量、步骤和小贴士。
- 按菜名或食材搜索，按分类、做菜时间和口味筛选。
- 随机推荐一道符合条件的菜；也可以只从当前菜单或收藏里选。
- 创建、重命名、删除菜单，添加和移除菜品。
- 记录自己的菜，编辑食材与做法；内置菜可以另存为自己的版本。
- 按人数调整数值食材用量，生成菜单的食材清单。
- 收藏、在当前浏览器自动保存、导出与导入 JSON 备份。
- PWA 配置、主屏幕图标、HTTPS 环境下的离线缓存。

## 在电脑和手机上试用

1. 解压整个项目，双击 `start.cmd`。也可以在项目目录运行 `node serve.cjs`（Node.js 18 或以上，无需 npm install）。
2. 电脑浏览器打开 `http://localhost:4173`。
3. 手机与电脑连接同一个 Wi-Fi，打开终端显示的 `Phone (same Wi-Fi)` 地址，例如 `http://192.168.1.5:4173`。
4. 使用时保持电脑和启动窗口开启。若手机打不开，先确认同一 Wi-Fi、地址是否变化，以及系统防火墙是否允许 Node.js 在私人网络访问；访客网络有时会隔离设备。

本机服务仅提供应用文件，不接收或存储你的菜谱。无需打开路由器公网端口。

## 长期在手机使用

把 `index.html`、`styles.css`、`app.js`、`recipes.js`、`sw.js`、`manifest.webmanifest` 和整个 `assets` 文件夹放到支持 HTTPS 的静态网站托管服务，保持相对路径不变。无需上传 `serve.cjs`、`start.cmd` 或本文档。

有 HTTPS 网址后，手机在任意网络下都能打开，不再需要电脑保持在线：

- iPhone：Safari 打开网址 → 分享 → 添加到主屏幕。
- 安卓：Chrome/Edge 打开网址 → 菜单 → 安装应用或添加到主屏幕。
- 首次在线打开、离线缓存完成后，再次打开支持离线使用。初次访问仍需联网。

局域网 HTTP 地址可以正常浏览和保存菜单，但完整安装和离线缓存通常需要 HTTPS（电脑上的 localhost 除外）。当前项目没有发布到公网。

## 数据保存与备份

数据保存在手机当前浏览器的 localStorage，不自动同步到其他设备。更换手机、浏览器、网址，或清理浏览器数据后，原数据可能不可见。使用首页右上角的按钮导出备份，换设备后导入即可。导入前会显示确认，因为会替换当前菜单、收藏和自定义菜品。

如果菜单较多，建议定期备份；不要只在无痕浏览模式里保存重要菜谱。

菜谱推荐使用内置和自定义内容进行本地筛选与随机选择。它不会联网生成新做法，也不包含餐厅定位、外卖或点餐功能。

## 文件结构

`recipes.js` 是内置菜谱；`app.js` 是交互与保存；`styles.css` 是界面；`sw.js` 是离线缓存。修改应用静态资源后，请同步递增 `sw.js` 的缓存版本，再重新部署。

如 4173 端口占用，在 PowerShell 中运行 `$env:KAIFAN_PORT = '4174'`，然后运行 `node serve.cjs`。
